# 🌾 Crop Production Prediction Using Machine Learning

## 📌 Project Overview
This project focuses on predicting expected crop production using Machine Learning regression techniques. It uses historical agricultural data to understand how factors such as crop type, state, district, season, year and cultivated area influence crop production.

## 🎯 Project Objectives
- Analyze historical crop production data.
- Perform data cleaning and preprocessing.
- Explore agricultural data using visualizations.
- Build a regression model to predict crop production.
- Evaluate the performance of the trained model.

## 📂 Dataset
- **Source:** Kaggle
- **Dataset:** Crop Production Dataset
- **Features:** State, District, Crop, Year, Season, Area and other available attributes.
- **Target Variable:** Production
